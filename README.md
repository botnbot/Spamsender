# Spamsender

**Spamsender** --- это веб-приложение на базе Django для управления
email-рассылками с ролевой системой доступа.

------------------------------------------------------------------------

## Возможности

-   Регистрация пользователей с подтверждением по email\
-   Активация аккаунта через токен\
-   Аутентификация (вход/выход)\
-   Управление пользователями (блокировка/разблокировка)\
-   Создание и редактирование email-рассылок\
-   Ролевая модель доступа (Администратор / Менеджер)\
-   Корректная обработка отказа в доступе с отображением сообщения
    вместо ошибки HTTP 403\
-   Кастомные management-команды для автоматизации задач

## Роли пользователей

### Администратор

-   Полный доступ ко всем объектам\
-   Может управлять пользователями\
-   Может управлять всеми рассылками

### Менеджер

-   Видит все объекты при наличии соответствующих permission\
-   Может блокировать пользователей, отключать рассылки\
-   Может создавать и редактировать свои рассылки\
-   Не может выполнять административные действия

### Обычный пользователь

-   Может работать только со своими объектами

------------------------------------------------------------------------

## Система разрешений

В проекте используются:

-   LoginRequiredMixin\
-   PermissionRequiredMixin\
-   Кастомный OwnerOrManagerMixin\
-   Встроенная система permissions Django

При отсутствии прав пользователь:

-   Получает сообщение "Нет доступа"\
-   Перенаправляется на безопасную страницу\
-   Не видит traceback ошибки

# Кастомные management-команды

В проекте реализованы пользовательские команды Django, расположенные в:

core/management/commands/

Команды позволяют автоматизировать администрирование и отправку
рассылок.

------------------------------------------------------------------------

##  Создание группы менеджеров

Файл: core/management/commands/create_managers_group.py

Команда создаёт группу **Managers** и назначает ей права:

-   view_all_messages\
-   view_all_recipients\
-   view_all_newsletters

### Запуск:

    python manage.py create_managers_group

## Работа с программой

###  Создание рассылки
1. Перейти в раздел **Рассылки → Создать рассылку**.
2. Заполнить форму:
   - **Название** (`subject`) — тема письма.
   - **Текст письма** (`text`) — содержимое.
   - **Дата начала/окончания рассылки** (`start_time`, `last_send_time`).
   - **Список получателей** — выбрать существующих или добавить новых.
3. Нажать **Создать**.
4. Рассылка сохраняется с владельцем = текущий пользователь.

###  Просмотр и редактирование
- Все свои рассылки видны в списке рассылок.
- Менеджеры с правами `core.view_all_newsletters` или суперпользователи видят все рассылки.
- Для редактирования:
  1. Перейти в детальный просмотр рассылки.
  2. Нажать **Редактировать**.
  3. Внести изменения и сохранить.

###  Ручная отправка рассылки
На главной странице нажать кнопку "Отправить все активные рассылки". 
1. Произойдет отправка всех активных рассылок через сервис `send_newsletter_now`.
2. После отправки отображается сообщение:
   ```
   Рассылка выполнена. Успешно: X, Неудачно: Y
   ```
или 
    1. Перейти в детальный просмотр нужной рассылки.\
    2. Нажать кнопку **Отправить сейчас**.\
    3. Система проверяет, что рассылка находится в разрешённом периоде:\
      ```python
        newsletter.start_time <= now <= newsletter.last_send_time
      ```\
    4. Отправка выполняется через сервис `send_newsletter_now`.\
    5. После отправки отображается сообщение:\
        ```
        Рассылка выполнена. Успешно: X, Неудачно: Y 
        ```\

###  Включение/отключение рассылки
- Менеджер может временно **отключить** рассылку.
- При отключении статус меняется на `STATUS_DISABLED`.
- При включении обратно — статус `STATUS_CREATED`.

###  Автоматическая фильтрация по владельцу
- Обычный пользователь видит только свои рассылки.
- Менеджеры и суперпользователи видят все рассылки, если у них есть `manager_permission`.
- Фильтрация по владельцу реализована через `OwnerOrManagerMixin`.

## Установка

### 1. Установка зависимостей

    poetry install

### 2. Применение миграций

    python manage.py migrate

### 3. Создание суперпользователя

    python manage.py createsuperuser

### 4. Создание группы менеджеров

    python manage.py create_managers_group

### 5. Запуск сервера

    python manage.py runserver
